《一個人也可以好好過生日》V1｜GitHub Pages 上傳說明

這是全新編寫的靜態網站。無須安裝套件、後端或登入。

上傳時，將本資料夾內的 index.html、styles.css、app.js、assets 資料夾一起放到 GitHub repository 的根目錄。請保留 assets 內的資料夾結構。不要只把 ZIP 檔上傳到 GitHub Pages；先解壓縮。

GitHub Pages 設定：Settings → Pages → Deploy from a branch → main → /(root)。儲存後開啟 Pages 網址測試。

測試順序：首頁 → 基本資料 → 選擇女生／男生版 → 早晨影片或跳過 → 9 個小片刻 → 送蛋糕影片或繼續 → 長按許願 → 麥克風或長按吹蠟燭 → 紀念卡下載。重新整理後再確認進度保留。

影片、音樂與蠟燭只在相應階段使用。瀏覽器拒絕影片或麥克風時，可用頁面上的跳過／長按方式繼續。玩家答案保存在當前瀏覽器的 localStorage；許願內容不輸入，也不保存。紀念卡照片僅在當次頁面使用，不上傳。

目前素材：女生早晨影片、男生早晨影片、送蛋糕影片、正式數字蠟燭 0～9 五種狀態、生日背景音樂。蛋糕靜態畫面擷取自正式送蛋糕影片的最後一幀。

預設人物素材尚未提供，因此這一包的紀念卡先支援玩家選照片，或不放照片。收到正式預設人物圖片後，可接入第三個選項。
